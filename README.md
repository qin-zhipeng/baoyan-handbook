## 一、这本手册解决什么问题

保研不是"成绩好就行"，它是一场 **资格 + 信息 + 材料 + 考核** 的系统工程。多数人卡住不是因为不努力，而是：

- 不知道**自己有没有资格**（校级办法 + 学院细则两套口径，门槛差很多）
- 不知道**每个时间点该干什么**（夏令营、预推免、九推三个阶段完全不同的打法）
- 不知道**材料怎么写得像自己**（简历、个人陈述、推荐信）
- 不知道**面试怎么准备**（专业、英语、综合三类问题）

这本手册把这四件事按顺序拆开，每个阶段给出「现在该做什么 + 常见坑 + 自检清单」。

## 三、适合谁

- **大一大二**：还没定型，最该先看 §02、§03，把资格条件和时间线对齐
- **大三**：正在打夏令营 / 预推免，直接看 §04–§09
- **家长**：想知道"孩子现在这个位置该做什么"，从 §01 和 §03 入手
- **刚入行的保研规划师**：这本是我 4 年一线交付整理出来的口径，可以当工作底稿

## 四、怎么读

先花三分钟做文首的**读前自检**，定位自己在哪个阶段，然后只读对应章节——全书按推进顺序写，没必要从头读到尾。第四章之后的附录（§15–§20）是工具页，建议打印出来按月勾。
